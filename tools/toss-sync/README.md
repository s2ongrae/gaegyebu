# 토스증권 → 가계부 동기화 (노트북 전용 · 조회 전용)

노트북에서 토스증권 Open API로 **보유 현황을 조회**해서 가계부 서버에 스냅샷으로 저장합니다. 가계부 앱(폰·PC)은 주식 탭 맨 위 **"토스증권 보유 현황"**에서 그걸 보여 줍니다.
- 주문·정정·취소 같은 **쓰기 기능은 코드에 없습니다**(허용된 GET 경로 + 토큰 발급만 보낼 수 있게 막혀 있음).
- 토스 키는 노트북의 `.env`에만 있고, 가계부 서버·앱·GitHub에는 가지 않습니다. 화면·로그에는 `***`로 가려집니다.
- 근거: 토스증권 공식 OpenAPI 명세 v1.2.14 (`openapi.tossinvest.com`). 경로: `/oauth2/token`, `/api/v1/accounts`, `/api/v1/holdings`, `/api/v1/buying-power`, `/api/v1/orders`(체결 내역), `/api/v1/exchange-rate`.

## 1. 처음 한 번
1. **토스증권 웹**(tossinvest.com) 로그인 → 설정 → **Open API** → 클라이언트 발급(`client_id`, `client_secret`).
2. 같은 화면 **허용 IP 관리**에 노트북의 공인 IP 등록. (집 와이파이에서 터미널: `curl ifconfig.me`)
3. `env.example`을 복사해 **저장소 밖** `gaegyebu-data/.env`로 만들고 값을 채우기:
   ```
   문서/
   ├─ gaegyebu/              ← 저장소
   └─ gaegyebu-data/
      ├─ .env               ← 토스 키 + 가계부 서버 주소·키
      └─ 가계부_백업.json
   ```
4. **가계부 서버 업데이트**: `server/Code.gs`를 Apps Script 편집기에 붙여 넣고 **배포 관리 → 기존 배포 수정 → 새 버전**(주소 유지). 스냅샷 저장(`saveStockSnapshot`)·조회(`loadStockSnapshot`) 기능이 새로 들어갔어요.

## 2. 쓰는 법 (이 폴더에서)
| 명령 | 하는 일 |
|---|---|
| `npm run check` | 연결 확인. 보유 종목·평가금액·손익·예수금을 표로 출력(서버로는 안 보냄). **토스 앱 숫자와 대조** |
| `npm run dry` | 스냅샷을 만들어 요약만 출력 + `gaegyebu-data/toss-snapshots/날짜.json` 사본 저장(서버 안 보냄) |
| `npm run sync` | 스냅샷을 가계부 서버에 저장 → 앱 주식 탭에 표시 |
| `npm test` | 가짜 토스 서버로 이 도구를 시험(실제 호출 없음) |

## 3. 폰 🔄로 받아 오기(대기 프로그램)
`node agent.js`를 켜 두면 20초마다 가계부 서버에 "폰에서 🔄를 눌렀는지" 물어보고, 눌렀으면 바로 동기화해요(1분 안).
- 앱 주식 탭 🔄 → 서버에 요청 표시(`requestTossSync`) → 노트북이 확인(`pollTossSync`) → 동기화(`saveStockSnapshot`) → 앱이 10초마다 새 현황을 확인해 다시 그림.
- 노트북이 확인할 때마다 시각이 남아서, 앱이 "노트북이 몇 분 전 마지막으로 확인했는지" 알려 줘요. 실패(허용 IP 등)하면 그 이유도 앱 알림에 떠요.
- 같은 요청은 한 번만 처리하고, 동기화는 1분에 한 번까지예요. 기록: `gaegyebu-data/toss-agent.log`. 두 번 켜도 하나만 돌아요.
- 노트북 시작 시 자동으로 켜기: 시작프로그램 폴더(`shell:startup`)의 `가계부 토스 대기.vbs`가 창 없이 `node agent.js`를 실행해요. 끄려면 그 파일을 지우고, 작업 관리자에서 `node.exe`(agent.js)를 끝내면 돼요.
- 시험: `node agent.js --once`(한 번만 확인).

## 3-1. 정해진 시각 자동 실행(선택, 윈도우)
평일 장 마감 후 16:10에 자동 동기화. 관리자 권한이 필요 없는 일반 작업으로 등록돼요(경로는 내 폴더로 바꾸기).
```
schtasks /Create /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 16:10 /TN "가계부 토스 동기화" /TR "cmd /c cd /d C:\Users\나\문서\gaegyebu\tools\toss-sync && node sync.js >> ..\..\..\gaegyebu-data\toss-sync.log 2>&1"
```
- 노트북이 켜져 있고(절전 X) **집 와이파이**일 때만 성공해요. 회사·카페에서는 허용 IP가 달라 403이 정상.
- 지우기: `schtasks /Delete /TN "가계부 토스 동기화" /F`
- 이 명령은 제가 실제 윈도우에서 실행해 보진 못했어요. 막히면 Claude Code에 "작업 스케줄러에 등록해 줘"라고 하세요.

## 4. 앱에서 보이는 것
- 총 평가금액(원화 환산: 해외는 매매기준율) · 평가손익/수익률 · 오늘 손익 · 예수금 · 세후 평가금액 · 환율
- 위험 신호: 한 종목 40% 이상, 상위 3종목 75% 이상, 해외 비중, 오늘 ±3% 이상
- 종목 비중 막대 · 보유 종목(평가금액/수익률/오늘 순 정렬) · 평가금액·원금 추이 차트(동기화한 날짜별) · 최근 31일 체결
- **반영 버튼**(확인 창 후 저장): 이번 달 `주식계좌` 자산값(예수금 포함/제외 선택), 이번 달 주식 원금
- 3일 넘게 동기화가 없으면 경고. 서버가 안 되면 마지막으로 받은 사본을 보여 줌

## 5. 문제 해결
- `허용 IP가 아닌 곳에서 호출했어요(403)` → 출력된 "지금 공인 IP"를 토스증권 웹 허용 IP에 등록(집 인터넷 IP는 통신사 사정으로 바뀔 수 있어요)
- `토큰 발급 실패` → `.env`의 키 확인(복사할 때 공백·따옴표)
- `가계부 서버 저장 실패: unauthorized` → `GAEGYEBU_SERVER_KEY`가 앱 ⚙️ 서버 설정의 키와 같은지 확인
- `가계부 서버 저장 실패: unknown_action` → 1-4의 서버 업데이트(새 버전 배포)를 안 한 것
- 호출 한도: 계좌 목록 초당 1회 등. 이 도구는 429를 받으면 `Retry-After`만큼 기다렸다 다시 해요.
